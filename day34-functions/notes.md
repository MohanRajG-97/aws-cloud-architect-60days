# Day 34 – Terraform Functions

## Concepts Learned

- join() combines list elements into strings.
- split() separates strings into lists.
- length() counts elements in lists.
- upper() converts text to uppercase.
- lower() converts text to lowercase.
- merge() combines multiple maps.
- concat() combines multiple lists.
- lookup() safely retrieves values from maps.

## Enterprise Learnings

- Functions reduce hardcoding.
- Functions improve maintainability.
- Functions enable dynamic infrastructure logic.
- Functions support enterprise naming conventions.
- Functions simplify tag management.
